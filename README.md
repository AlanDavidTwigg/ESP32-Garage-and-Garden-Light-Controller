Project for ESP32, control multiple external 12V garden lights, interior garage LED spotlights, front and rear garage  door  magnetic reed relays, IRLZ44N via Mosfet driver chip.
Alexa integration, NTP and automatic daylight savings, internal garage lights are, when triggered,on for 10 minutes then automatically go off.
PCB with Dallas temperature sensor and Opto couplers for the front & rear garage door sensors.
Syslog logging.
